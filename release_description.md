# LGL Emoji Picker v1.5.2

Highlights:

- The header bar now shows the app icon and name, matching the other LGL apps.
- **Ctrl+Shift+M** (or **Use System Title Bar** in the menu) switches to your
  desktop's own title bar and back. The choice is remembered.
- Tap **Alt** to open and close the main menu.
- The application ID is now `com.linuxgamerlife.lgl-emoji-picker`. If you had
  the picker pinned to a panel or dock, pin it again after updating.

Install on Fedora:

```sh
sudo dnf copr enable linuxgamerlife/lgl-toolkit
sudo dnf install lgl-emoji-picker
```
